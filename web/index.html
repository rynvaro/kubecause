KubeCause Slice 4 通用 Agent + 对话模式

两种用法共用同一套 Agent 核心、同一套工具、同一套安全规则：单次诊断是填 namespace / 类型 / 名字 / 问题，点提交，等报告，可审批、可执行、可验证；对话模式是一问一答，先问“当前状态怎么样”，再追问某个 namespace 是怎么回事，Agent 记得上文，只读不改。想修复时，对话里只给一张建议卡，点“转成正式诊断”后才走审批和执行。
